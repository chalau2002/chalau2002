## About

<p>
  Data Scientist at FC Porto, previously working at SC Braga, with experience in football analytics, data engineering and the development of data-driven tools for match analysis and scouting.
  Currently focused on building and maintaining data platforms, based on Databricks, including data pipelines, the Gold layer and the KPI catalog. I also develop internal analytics applications with Python backends and React frontends, delivering insights and tools used by the coaching staff to support decision-making.
</p>
